# Open 证据｜开放增强

本目录用于存放开放增强功能的证据。

## 已实现的开放增强

### 1. 优先关注算法（D2）
- 基于环境权重×2 + flowLevel + 连续异常×0.5
- 不写死断面，完全数据驱动
- 可解释的优先度理由

### 2. 消息健壮性（D3）
- 事件消息带 seq 号，重复/过期消息丢弃
- eventId 匹配校验
- 错误 JSON 拒绝不崩溃
- 非法状态转移被拒绝（OPEN 不能直接 → RECOVERED）

### 3. 规则/ML 组合裁决（D5）
- 3 种策略对比（规则优先 / ML 优先 / 组合裁决）
- 推荐策略C：两者皆异常才报警，不一致转人工复核

### 4. 3D 状态驱动视觉（E1）
- 水面颜色随 4 种状态变化
- 水面高度随 waterLevel 归一化
- 洪水预警时波动幅度加大 + 标记闪烁

### 5. 多模态交互（E2）
- 语音指令控制（查看断面 / 播报状态 / 事件操作）
- 摄像头画面叠加实时状态
- 异常事件自动语音播报
