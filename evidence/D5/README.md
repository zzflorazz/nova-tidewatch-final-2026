# D5 证据｜固定规则与 ML 辅助判断

核心观点：**规则回答"是否越界"（阈值），ML 回答"是否偏离历史分布"—— 两个问题不同，不一致是正常现象。**
裁决不等于删掉另一个：两种判断依据始终并列可见。

## 实际运行结果（data/history.csv 60 条，同一模型）

| 交叉情况 | 数量 | 说明 |
|----------|------|------|
| 确认异常（规则异常 + ML异常）| 6 | 相互印证（4 条水质浑浊 + 2 条洪水预警）|
| 规则异常 + ML常态 | 13 | 越界但历史分布中常见（7 条警戒 + 3 条洪水 + 3 条浑浊）|
| 规则正常 + ML异常 | 0 | 本数据中 ML 异常点均同时被规则判为异常 |
| 一致正常 | 41 | |
| **一致率** | **78.3%** | |

组合裁决策略统计（报警数 / 需复核数）：
| 策略 | 报警 | 需复核 |
|------|------|--------|
| A 规则优先 | 19 | 0 |
| B ML 优先 | 19 | 0 |
| **C 组合裁决（推荐）** | **6（确认报警）** | **13** |
